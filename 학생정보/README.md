# 학생정보 입력 안내

이 폴더에는 세특 작성의 근거가 되는 교사의 관찰 기록을 YAML 형식으로 저장합니다.

## 기본 원칙

- `template.yaml`은 직접 수정하지 않고 복사하여 사용합니다.
- 실제로 확인한 수업 활동과 관찰만 기록합니다.
- 주민등록번호, 연락처, 주소 등 세특 작성에 불필요한 개인정보는 입력하지 않습니다.
- 한 학생에게 활동이 여러 개라면 `activities` 아래에 활동 묶음을 추가합니다.
- 긴 문장보다 구체적인 행동, 결과, 근거를 짧게 나누어 입력합니다.
- 해당 내용이 없으면 임의로 채우지 말고 빈 문자열(`""`)이나 빈 배열(`[]`)로 둡니다.

## 주요 항목

| 항목 | 의미 |
| --- | --- |
| `motivation` | 학생이 탐구나 활동을 시작한 계기 또는 문제의식 |
| `process` | 학생이 실제로 수행한 행동과 탐구 절차 |
| `evidence` | 결과를 뒷받침하는 측정값, 발표 내용, 보고서 등의 근거 |
| `result` | 활동을 통해 도출한 결론이나 산출물 |
| `competencies` | 활동에서 드러난 교과 역량 |
| `growth` | 생각, 태도, 방법이 어떻게 변화했는지 보여 주는 내용 |
| `teacher_observation` | 교사가 직접 관찰한 구체적인 행동 |
| `requirements` | 목표 분량, 강조점, 제외할 내용 등 출력 조건 |

## 파일 이름

현재는 이해하기 쉬운 이름을 사용할 수 있지만, 실제 운영 환경에서는 학생 이름 대신 내부 식별번호를 파일명으로 사용하는 방식을 권장합니다.

예: `2026-2-03-12.yaml`

학생별 YAML 파일은 `.gitignore`에 의해 Git 추적 대상에서 제외됩니다. 단, 파일을 메일이나 메신저로 전송하거나 클라우드 동기화 폴더에 저장할 때의 개인정보 보호는 별도로 확인해야 합니다.
