# 학생 세특 작성 워크플로

저장소 루트의 `AGENTS.md`에서 `세특 파이프라인 트리거`부터 `완료 보고`까지를 마스터 절차로 사용한다.

1. 현재 요청에 학생정보 YAML 경로나 식별자가 있는지 확인한다.
2. 없으면 `학생정보/` 안의 정확한 YAML 파일명을 하나만 요청한다. 다른 학생 파일을 열어 찾지 않는다.
3. 입력 파일이 결정되면 `.agent/01_data_structuring.md`부터 순서대로 실행한다.
4. 최종 파일을 저장한 뒤 Linter 명령을 제시하고 승인을 기다린다.
5. 승인 후 JSON 결과에 따라 최소 수정하고, 재검사마다 다시 승인을 받는다.
6. 오류 0건이면 교사 검토와 새 채팅 사용을 안내한다.

이 워크플로를 호출했다는 사실만으로 기존 결과 파일 덮어쓰기나 터미널 명령 실행을 승인한 것으로 간주하지 않는다.
