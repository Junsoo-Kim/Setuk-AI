# 초안 검토 체크포인트 저장소 (run_state)

세특·창체 파이프라인이 초안(DRAFT_V1)을 완성한 뒤, 교사 검토를 기다리는 동안의 진행 상태를 기록하는 폴더입니다. `scripts/run_state.py`와 `scripts/review_cli.py`가 이 폴더의 파일을 읽고 씁니다.

- `<식별자>.json`: 현재 단계(status)와 각 단계 산출물을 담은 체크포인트. 학생 식별 가능한 초안 본문을 포함할 수 있습니다.
- `<식별자>_review.md`: 교사가 직접 열어 초안을 검토·수정하는 동안만 존재하는 임시 파일입니다. 승인 또는 반려 시 자동으로 삭제됩니다.

두 파일 모두 개인정보 보호를 위해 Git 추적 대상에서 제외됩니다. 이 안내 파일만 저장소에 포함됩니다.

체크포인트는 대상 학생의 세특/창체 작업이 Linter 통과까지 완전히 끝나면 삭제됩니다(AGENTS.md 6번 완료 보고 참고). 작업 중간에 채팅을 닫아도 같은 식별자로 다시 시작하면 이 파일에서 이어갈 수 있지만, 다른 학생과 섞이지 않도록 새 학생은 항상 새 채팅에서 시작하세요.
