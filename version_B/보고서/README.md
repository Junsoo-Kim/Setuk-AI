# 학생 보고서 입력 폴더

세특 입력 YAML을 자동으로 만들 때 사용하는 학생별 Word 보고서(`.docx`)를 이 폴더에 둡니다.

- DOCX 하나에는 학생 한 명의 보고서만 포함하는 것을 권장합니다.
- 파일명에 학생명을 정확히 포함하세요. 예: `이세비_물리학Ⅱ_주제탐구보고서.docx`
- 같은 학생명이 들어간 DOCX가 둘 이상이면 AI가 임의로 선택하지 않고 정확한 파일을 요청합니다.
- `~$`로 시작하는 Word 임시 파일은 처리하지 않습니다.
- 이미지나 그래프에만 핵심 결과가 있고 본문 설명이 없으면 자동 추출이 중단될 수 있습니다.
- 실제 DOCX는 개인정보 보호를 위해 Git과 배포 ZIP에 포함되지 않습니다. 이 안내 파일만 추적됩니다.
- 새 버전 ZIP을 다시 압축 해제하면 이전 폴더의 DOCX가 자동으로 옮겨지지 않습니다. 테스트할 DOCX를 새 폴더의 `보고서/`에 다시 복사해야 합니다.

보고서 원본은 읽기 전용으로 사용되며, 추출 결과는 `학생정보/<학생명>.yaml`에 저장됩니다. 기존 YAML이 있으면 덮어쓰기 전에 승인을 요청합니다.
