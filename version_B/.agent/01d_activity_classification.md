# 01d. 창체(진로활동·자율활동) 분류 전용 모드

## 역할

`보고서/`에 있는 지정 학생의 `.docx`를 모두 읽고, 각 보고서가 진로활동과 자율활동 중 어느 쪽에 더 맞는지 판단해 채팅으로만 보고한다. `01c_activity_report_ingestion.md`와 달리 YAML을 만들지 않으며, 02·03c·04 단계로 이어지지 않는다. 이 지침은 여기서 끝난다.

## 입력

- 사용자가 지정한 학생명만 필요하다. 순위 목록이나 항목(진로활동/자율활동) 지정은 필요 없다 — 이 순위를 대신 정해주는 것이 이 모드의 목적이다.

## 보고서 파일 결정

`01c_activity_report_ingestion.md`의 "보고서 파일 결정" 1·5번 규칙을 그대로 적용한다.

1. `보고서/`에서 파일명에 학생명이 포함된 `.docx`를 전부 나열한다. 문서 내용을 열어 학생을 탐색하지 않는다. `~$`로 시작하는 Word 임시 파일은 제외한다.
2. 정규화한 경로가 `보고서/` 밖을 가리키거나 확장자가 `.docx`가 아닌 파일은 후보에서 제외한다.
3. 후보가 0개면 진행하지 않는다. 현재 작업공간의 `보고서/` 절대 경로와 발견된 DOCX 파일명만 보고하고, 학생명 철자나 파일 위치를 확인해 달라고 요청한다.
4. 후보가 1개면 비교 대상이 없으므로 분류 로직(아래)으로 그 1개가 어느 쪽에 더 맞는지만 밝히고, 반대 카테고리는 "해당 없음"으로 보고한다. 강제로 양쪽에 나누지 않는다.
5. 순위 목록이나 항목 지정은 받지 않는다. 사용자가 이번 요청에 순위나 항목을 함께 지정했다면 이는 C모드(`AGENTS.md`의 "C. 순위 기반 다중 보고서 입력 모드") 요청이므로 D모드를 실행하지 않고 C모드 트리거인지 사용자에게 확인한다.

## DOCX 텍스트 추출

확정된 파일마다 다음 형식으로 포터블 추출기를 실행하여 문단과 표 텍스트를 UTF-8 JSON으로 받는다. 한 번의 명령에는 파일 하나만 인자로 전달하며, 확정된 파일 수만큼 반복 실행한다.

```powershell
& '.\python_portable\python.exe' '.\scripts\extract_docx.py' '.\보고서\<보고서파일>.docx' '--json'
```

- 종료 코드가 0이 아니거나 JSON을 읽을 수 없는 파일이 있으면 해당 파일만 분류 대상에서 제외하고, 나머지 확정 파일로 계속할지 사용자에게 확인한다.
- 인터넷 검색이나 외부 자료로 보고서 내용을 보충하거나 사실을 교정하지 않는다.

## 손상되거나 이해할 수 없는 보고서 처리

`01_report_ingestion.md`의 "손상되거나 이해할 수 없는 보고서 처리" 기준(추출 오류, 극히 적은 문단, 빈 견본 양식, 판단 불가능한 내용, 요청 주제와 무관해 보임)을 그대로 적용한다. 문제가 일부 파일에서만 발생하면 임의로 제외하지 않고, 무엇이 문제인지 설명한 뒤 (a) 문제 파일을 제외하고 나머지로 분류를 계속할지 (b) 전체 작업을 중단할지 사용자에게 확인한다.

## 학생 신원 확인

파일마다 `01c_activity_report_ingestion.md`의 "학생 신원 확인" 절을 그대로 적용한다. 요약: 본문 학생명이 지정 학생명과 다르면 그 파일만이 아니라 작업 전체를 즉시 중단한다. 확정된 파일들 사이에서 학번 표기가 실질적으로 달라 충돌하면 임의로 하나를 선택하지 않고 보고한다.

## 분류 기준

각 보고서를 두 축으로 평가한다. 어느 한 값을 억지로 계산하지 않고, 본문 근거로 판단할 수 있는 만큼만 상대적으로 비교한다.

- **진로 신호**: 특정 직업·전공·학문 분야의 심화 탐구, 진로와 관련된 인물(학자·전문가)의 연구나 삶 탐구, 진로 분야의 최신 동향·쟁점 조사, 진로 진출과 직접 연결되는 문제 해결 활동.
- **자율 신호**: 학급·학년 단위로 이루어진 자기주도 활동, 특정 진로 방향과 직접 연결되지 않는 교양적·범교과적 탐구, 협력·공동체·자치 활동.

규칙:

1. 각 보고서를 두 신호 중 더 강하게 드러나는 쪽으로 배정한다. "진로 역량이 더 뚜렷하게 드러나는 보고서일수록 진로활동 쪽"이 핵심 기준이다.
2. 보고서 개수가 4개가 아니어도(1~3개) 균등 배분을 강제하지 않는다. 내용상 자연스러운 분포(예: 2:1, 3:0, 1:0)를 그대로 보고한다.
3. 두 신호가 비슷하게 나타나 어느 한쪽으로 판단하기 어려운 보고서는 임의로 배정하지 않고 "애매 — 교사 확인 필요"로 별도 표시한다. 근거가 부족한 상태에서 추측으로 채우지 않는다는 이 하네스의 공통 원칙을 그대로 따른다.
4. 카테고리 안에서는 해당 카테고리 신호가 강한 순서대로 순위를 매긴다(1순위가 가장 강함).
5. 보고서 본문에 없는 진로 계획이나 역량을 만들어 신호로 사용하지 않는다.

## 결과 보고 형식

파일을 저장하지 않는다. 채팅 응답에 다음 형식으로만 보고한다.

```
## 진로활동 후보
| 순위 | 파일명 | 분류 근거(1줄) |
| --- | --- | --- |
| 1 | ... | ... |

## 자율활동 후보
| 순위 | 파일명 | 분류 근거(1줄) |
| --- | --- | --- |
| 1 | ... | ... |
```

- 후보가 없는 카테고리는 표 대신 "해당 없음"만 적는다.
- "애매 — 교사 확인 필요" 항목은 두 표 어디에도 넣지 않고 표 아래에 별도로 나열한다.
- 보고서 전문이나 학생 개인정보를 채팅에 반복 출력하지 않는다. 분류 근거는 한 줄 요약으로만 제시한다.
- 마지막에 다음 안내를 반드시 덧붙인다: "이 결과는 어떤 파일도 저장하지 않았습니다. 실제 작성은 새 채팅에서 `<학생명> 진로활동 작성해. <파일 키워드> 1순위, ...` 또는 `<학생명> 자율활동 작성해. ...` 형식으로 요청하세요."
