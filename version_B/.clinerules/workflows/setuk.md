# 학생 세특 작성 워크플로

저장소 루트의 `AGENTS.md`에서 `세특 파이프라인 트리거`부터 `완료 보고`까지를 마스터 절차로 사용한다.

1. 현재 요청에 보고서 DOCX 경로, 학생정보 YAML 경로 또는 학생명이 있는지 확인한다.
2. 학생명 또는 DOCX가 지정되면 `.agent/01_report_ingestion.md`로 해당 보고서 하나를 YAML로 변환한다.
3. 기존 YAML 경로가 명시된 경우에만 보고서 입력 단계를 생략한다.
4. YAML 입력 파일이 결정되면 `.agent/02_data_structuring.md`부터 순서대로 실행한다. 03(초안) 완성 직후에는 `AGENTS.md`의 "2-A. Human-in-the-Loop 체크포인트"를 거쳐 교사 승인을 받은 뒤에만 04(평가·저장)를 실행한다.
5. 최종 파일을 저장한 뒤 Linter 명령을 제시하고 승인을 기다린다.
6. 승인 후 JSON 결과에 따라 최소 수정하고, 재검사마다 다시 승인을 받는다.
7. 오류 0건이면 교사 검토와 새 채팅 사용을 안내한다.

이 워크플로를 호출했다는 사실만으로 기존 결과 파일 덮어쓰기나 터미널 명령 실행을 승인한 것으로 간주하지 않는다.
