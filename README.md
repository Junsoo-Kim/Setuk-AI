# Setuk-AI

고등학교 교사의 세부능력 및 특기사항(세특) 작성을 돕는 AI 하네스입니다. 사용 환경과 비용 부담이 다른 세 개의 독립된 버전으로 나뉘어 있으며, 서로의 파일을 참조하지 않습니다. 각 버전의 상세 설계와 비교는 `기획서.md`를 참고하세요.

| 폴더 | 버전 | 실행 환경 | 비용 | 상태 |
| --- | --- | --- | --- | --- |
| [`version_A/`](version_A/) | A버전 | 웹 (Claude Project 등 지식 베이스 업로드) | 웹 채팅 요금제 안에서 해결 | 완료, 동결 |
| [`version_B/`](version_B/) | B버전 | 로컬 VSCode + Claude Code(또는 Cline/Codex) 구독 | 구독료 외 추가 없음, 무설치 | 고도화 진행 중 |
| [`version_C/`](version_C/) | C버전 | 로컬 웹 서버, Claude API 직접 호출 | 구독료 + API 종량 과금 | v1 구현 완료 |

## 어떤 버전을 써야 하나요

- **가장 간편하게 바로 써보고 싶다면** → `version_A/`의 파일들을 Claude Project 같은 웹 지식 베이스에 올려서 사용하세요.
- **클로드 구독만으로, 추가 비용 없이 로컬에서 쓰고 싶다면** → `version_B/`를 VSCode에서 워크스페이스로 엽니다. 압축 배포본 사용법은 `version_B/사용안내.md`, 개발 문서는 `version_B/README.md`를 참고하세요.
- **비용을 감수하고 가장 정교한 결과(자율 멀티에이전트 + 웹 검토 화면)를 원한다면** → `version_C/README.md`를 따라 설치하세요.

## 이 저장소에서 개발하기

- B버전 AI 파이프라인을 실제로 실행하려면(Codex/Cline/Claude Code가 `AGENTS.md`를 인식해야 하므로) 저장소 루트가 아니라 **`version_B/` 폴더 자체**를 VSCode 워크스페이스로 열어야 합니다.
- `기획서.md`: 세 버전 전체를 아우르는 기획 문서. 버전 비교, 각 버전의 설계 결정과 남은 일이 정리되어 있습니다.
- `개선 계획.md`: 3버전 구도로 정리되기 전의 초기 논의 초안(역사적 기록으로 보존).
